# argonctl Utility

## Why do you need another cli tools?

The idea was to replace the original but this is more of a tool box and will optional to build.

It will consist of modules that will be easy to access and use.

## Modules

* fan - this module is to allow for control over the fan with or without a running daemon.
* mode - this module will allow for setting of the daemon's mode.
* ir - this module is to allow for setting up of the IR codes used by the Argon One.
* schedule - this module is for changing the set points use in fan control.
* conf - this module will allow the daemon to save it's current configuration or load a new one on the fly.
* diagnostic - this module will be a tool for finding and solving issues.

There are some others planned.
